# Bedrock face material

Rock Face 03, Poly Haven: https://polyhaven.com/a/rock_face_03

Photography: Dario Barresi. Processing: Rico Cilliers.
CC0: https://polyhaven.com/license (checked 22 October 2026).

The 1K diffuse and displacement images are converted to WebP at quality 90 by
`scripts/fetch-bedrock-textures.mjs`. Original source MD5:

- Diffuse: `e4c34abb1aad5befe12754fad507147a`
- Displacement: `9d51d6b2496de79f97b80d43ff1dd7fb`

This is a seamless material for the authored stone surfaces, not a new terrain
scan or exact geological reproduction. Height is used for restrained shader
bump only; collision geometry is unchanged. Reference texture width is 2.7 m.
