# Trail ground textures

Source: Poly Haven, licensed CC0 1.0: https://polyhaven.com/license

- `earth.webp`, `earth-normal.webp`: Brown Mud, https://polyhaven.com/a/brown_mud
- `forest.webp`: Brown Mud Leaves 01, https://polyhaven.com/a/brown_mud_leaves_01
- `gravel.webp`, `gravel-normal.webp`: Gravelly Sand, Dario Barresi, https://polyhaven.com/a/gravelly_sand
- `rocky-slope.webp`: Rocky Terrain, Amal Kumar, https://polyhaven.com/a/rocky_terrain

Downloaded 21 October 2026 from the official 1K JPG distribution, verified against the MD5 values in Poly Haven's file metadata, then converted to WebP. Original download URLs and checksums are in `scripts/fetch-trail-textures.mjs`. Assets are bundled locally; visitors do not call the source API. Repeated texture detail is visual only; the shared terrain heightfield controls vehicle contact.
