# Bridge timber surface

The bridge uses **Weathered Planks** by Dimitrios Savva (photography) and Dario Barresi (processing), published by Poly Haven under **CC0 1.0**.

Primary sources verified 21 October 2026:

- Asset: https://polyhaven.com/a/weathered_planks
- License and redistribution terms: https://polyhaven.com/license
- Official file manifest: https://api.polyhaven.com/files/weathered_planks

Only the freely redistributable diffuse, OpenGL-normal and roughness maps are included. No website preview renders, logos or marketing artwork are used. `scripts/fetch-bridge-textures.mjs` records the original file fingerprints and reproduces the 1k WebP copies. Surface scale is approximately two metres per texture tile. The physical deck remains an original bridge model and a single continuous safe driving collider, with individual thin timber planks rendered inside that envelope.
